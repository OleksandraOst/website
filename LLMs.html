LLMs Projects

Clinical Reasoning Assistant

Clinical Reasoning Assistant is a self-evolving benchmarking system for evaluating large language models on complex reasoning tasks. It uses a multi-agent architecture (Generator, Solver, and Judge) where one model generates novel questions, another attempts to solve them, and a third evaluates the response. The system dynamically adjusts question difficulty based on model performance, creating an adaptive benchmark that continuously tests reasoning capabilities.

Surway

Surway is an AI-powered survey analytics tool designed to help organizations extract insights from customer feedback. The system performs sentiment analysis and text processing using a locally deployed transformer model, ensuring sensitive data never leaves the environment. Surway automatically analyzes survey responses, tracks sentiment trends over time, and generates summaries to support data-driven decision making.
