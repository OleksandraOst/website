Machine Learning Projects

Antibody-Antigen Interactions with AI

This project explored challenges in machine learning for predicting antibody–antigen interactions, a key problem in drug discovery. While modern structure prediction systems such as AlphaFold models achieve strong performance in general protein structure prediction, their accuracy for antibody–antigen complexes remains limited. As part of an ICLR 2026 workshop submission, I contributed to research on improving large-scale machine learning evaluation in this domain. My work focused on data management strategies and infrastructure design for benchmarking ML models on antibody–antigen interaction prediction tasks.

ML for Molecules

This project focused on applying machine learning to accelerate the discovery of stable materials for organic light-emitting diode (OLED) displays. Blue OLED pixels degrade faster than red and green ones due to lower luminous efficiency, which requires higher operating currents and reduces device lifetime. I developed an end-to-end machine learning pipeline in Python using PyTorch and scientific computing tools to transform raw materials datasets into model-ready features and train classification and regression models. The system was designed to identify molecular candidates with high photoluminescence quantum yield (PLQY), a key property for improving the stability and efficiency of blue OLED emitters.
